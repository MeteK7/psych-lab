# CLAUDE.md

## Git commit messages and operations

These rules are permanent.

### Commit messages
- Never include AI attribution, co-author information, signatures or acknowledgements in commit messages.
- Never add `Co-Authored-By`, "Generated by AI" or similar trailers.
- Do not mention AI involvement in any commit message.
- Write concise commit messages based strictly on the actual code changes.
- Group related edited files logically, and write a separate commit message for each distinct group when appropriate.
- Follow the Conventional Commits format (`feat:`, `fix:`, `refactor:`, `chore:` and so on).
- When asked for commit messages, output only the commit messages, without unnecessary explanation or commentary.

### Git operations
- Never commit changes automatically, and never create a commit unless explicitly asked.
- Never merge branches automatically, and never merge unless explicitly asked.
- Fetch remote changes with `git fetch` when needed.
- Do not push unless explicitly asked.
- Always leave changes in the working tree for review.
- Ask for explicit permission before any commit, merge, rebase or push.
